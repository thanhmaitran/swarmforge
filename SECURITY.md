# Security Policy

SwarmForge is simulation software and is **not** intended to control physical robots or safety-critical systems.

* Report vulnerabilities privately through GitHub Security Advisories (preferred) or by contacting the maintainers.
* Please include version, reproduction steps and impact. We aim to acknowledge reports within 7 days.
* The HTTP API has no authentication and is meant for local development; do not expose it to untrusted networks.
