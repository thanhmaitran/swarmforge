# Environment setup

See [Installation](../user-guide/installation.md). Recommended on Windows 11: VS Code (Python, Pylance, C/C++,
CMake Tools, Remote - WSL, GitLens, Even Better TOML), Python 3.12, MSVC Build Tools, CMake, WSL2 Ubuntu 24.04
for ROS 2 Jazzy + Gazebo Harmonic. Run `pre-commit install` after cloning.

Typical commands: `make check`, `make cpp-test`, `make native`, `make experiments-quick`, `make docs`.
